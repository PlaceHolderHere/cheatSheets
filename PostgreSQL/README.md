Sources:
    * Freecodecamp: https://www.youtube.com/watch?v=qw--VYLpxG4
    * Documentation: https://www.postgresql.org/docs/current/index.html

General psql commands:
    - after logging into psql and a database, you can execute commands and sql queries
    * \? -> list psql commands (Commands from the postgresql command line)
    * \h -> list sql commands
    * \l -> list databases
    * CREATE DATABASE [name];
    * CREATE TABLE (columns...);
    * \d -> list tables
    * \d [table_name] -> describe table
